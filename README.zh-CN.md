# 凉山彝文安卓输入法 (Liangshan Yi Script Android IME)

基于提供的彝文词库文件制作的安卓彝文（诺苏语 / Nuosu Yi）输入法软件。

## 功能特点

- **拼音输入**：支持全拼/简拼（基于词库拉丁转写），实时候选
- **部首输入**：根据《规范彝文词典》26 个部首检字法，可按部首浏览并选择彝文字
- **笔画输入**：新增！支持笔画简拼/全拼码快速输入部首字形，也可直接在笔画面板选择
- 加载完整彝文词库（约 5 万+ 条目）+ 词典示例补充
- 候选词实时匹配与选择
- 支持单字、词组输入
- 简单 QWERTY 键盘（用于输入拼音码）
- 键盘「部首」键切换部首模式，「笔画」键切换笔画模式

## 词库来源

1. `彝文输入法彝文词库完整版.ini.TXT`（主词库）
2. 《规范彝文词典（ꆈꌠꁱꂷꎹꏦꋐ）》部首检字法示例（补充部分字与拼音映射）

词库格式示例：
```
it=1,ꀀ
itwu=1,ꀀꀕ
itiqi=1,ꀀꀂꏾꌠꐑ,ꌞꀂꏾꀂꐑ
```

左侧为输入码（拼音），右侧为频率与彝文候选。

## 如何使用

1. 用 **Android Studio**（推荐 Hedgehog 或更新版本）打开本项目根目录
2. 等待 Gradle 同步完成（首次会下载依赖）
3. 如果提示缺少 Gradle Wrapper，可在 Android Studio 中点击 “Create Gradle Wrapper”
4. 连接真机或启动模拟器（API 21 及以上）
5. 点击 Run 安装 APK
6. 安装后进入系统设置：
   - **设置 → 系统 → 语言和输入法 → 屏幕键盘 / 虚拟键盘 → 管理键盘**
   - 启用「**凉山彝文输入法**」
7. 打开任意可以输入文字的 App（备忘录、微信等），长按输入框或点击键盘切换图标，选择本输入法
8. 输入拼音码示例：
   - `it` → ꀀ
   - `mu` → ꃅ
   - `nyi` → ꑌ
   - `itwu` → ꀀꀕ
   - 空格键可快速上屏第一个候选
9. **部首输入**：点击键盘「部首」键 → 选部首 → 选字上屏
10. **笔画输入**：点击键盘「笔画」键 → 在面板中选择笔画码对应的字形直接上屏。也可在拼音模式下直接输入如 `qotb`、`lib`、`nyipb` 等笔画码

### 常见问题

- **词库加载慢**：首次启动会解析约 5 万条词库，建议在后台线程完成（已实现）。可在 Logcat 过滤 `YiDictionary` 查看进度。
- **KeyboardView 警告**：系统 `KeyboardView` 已废弃，本项目仅作演示。正式产品建议使用自定义 View 或第三方键盘库。
- **找不到输入法**：确认已在系统设置中启用，并重启一次输入法服务。

## 技术说明

- 语言：Kotlin
- 最低 SDK：21
- 目标 SDK：34
- 词库加载：启动时解析 INI 文件到内存 Map + 简单前缀索引
- 匹配：前缀匹配，按频率排序候选

## 注意事项

- 本项目为教学/演示用途，键盘布局较简化，实际可扩展为更专业的彝文专用键盘
- 词库较大（~1.5MB），首次加载需要几秒时间
- 未实现用户词库学习、云同步等高级功能
- 部分词库条目含中文注释或特殊字符，解析时已做简单过滤
